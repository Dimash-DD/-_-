# Ordinem servare

**ISIS-Tech** · проверка раздела ОВ (отопление, вентиляция, кондиционирование) по PDF чертежам.

Проверяет комплект рабочих чертежей по ГОСТ 21.602-2016 и СП РК 4.02-101-2012 и выдаёт:

- сводный отчёт: **А. Оформление**, **Б. Технические замечания**, **В. Аудит Claude**;
- PDF с комментариями: кружок с номером на месте каждого замечания;
- таблицу CSV для Excel.

## Что проверяется

| Оформление | Технические |
|---|---|
| шифр и наименование объекта в штампах | подписи сечений против нарисованной ширины воздуховода |
| стадия, номера листов, подписи, графа организации | выноски оборудования против спецификации |
| состав комплекта (общие данные, схемы, спецификация) | толщина стали воздуховодов (прил. Ж.2), соотношение сторон |
| обозначения систем по табл. 1 ГОСТ 21.602 | огнезадерживающие клапаны (7.10.1, 7.10.9, 7.10.13) |
| наименования листов, масштабы | дымовые и нормально закрытые клапаны (9.13, 9.19) |
| | транзитные воздуховоды через лестничные клетки (7.10.14) |

## Запуск

Нужен Python 3.10+ и библиотека PyMuPDF:

```
python -m pip install pymupdf
```

Двойной щелчок по `Ordinem servare.pyw` — откроется окно программы.
Для аудита через API Claude дополнительно: `python -m pip install anthropic` и ключ API в настройках.

## Файлы

| Файл | Назначение |
|---|---|
| `Ordinem servare.pyw` | запуск программы |
| `ov_app.py`, `ui.html` | окно программы (локальный сервер + интерфейс) |
| `ov_audit.py` | полный прогон проверки |
| `ov_check.py` | подписи сечений воздуховодов против геометрии PDF |
| `ov_album.py` | штамп, шифр, состав комплекта, обозначения, спецификация |
| `ov_tech.py` | технические проверки по СП РК 4.02-101 |
| `ov_norms.py` | база нормативов: разбор PDF по пунктам и поиск |
| `ov_marks.py` | PDF с комментариями |
| `ov_report.py` | сводный отчёт |
| `ov_ai.py` | аудит Claude через API (по желанию) |
| `ov_config.py`, `Справочники/` | справочники оборудования и слоёв (правятся в Excel) |

Нормативные документы в репозиторий не входят: программа читает их из папки
`Рабочий стол\Нормативная документация для проверки`.
