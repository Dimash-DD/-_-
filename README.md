# Ordinem servare

**ISIS-Tech** · проверка раздела ОВ (отопление, вентиляция, кондиционирование) по PDF чертежам.

Проверяет комплект рабочих чертежей по ГОСТ 21.602-2016 и СП РК 4.02-101-2012 и выдаёт:

- сводный отчёт: **А. Оформление**, **Б. Технические замечания**, **В. Аудит Claude**;
- PDF с комментариями: кружок с номером на месте каждого замечания;
- таблицу CSV для Excel.

Все результаты сохраняются рядом с чертежом в папке «<имя файла чертежа>_отчет»
(или в такой же папке внутри «Папки для результатов», если она задана в настройках).

## Что проверяется

| Оформление | Технические |
|---|---|
| шифр и наименование объекта в штампах | подписи сечений против нарисованной ширины воздуховода |
| стадия, номера листов, подписи, графа организации | выноски оборудования против спецификации |
| состав комплекта (общие данные, схемы, спецификация) | толщина стали воздуховодов (прил. Ж.2), соотношение сторон |
| обозначения систем по табл. 1 ГОСТ 21.602 | огнезадерживающие клапаны (7.10.1, 7.10.9, 7.10.13) |
| наименования листов, масштабы | дымовые и нормально закрытые клапаны (9.13, 9.19) |
| | транзитные воздуховоды через лестничные клетки (7.10.14) |

## Запуск

Нужен Python 3.10+ и библиотека PyMuPDF:

```
python -m pip install pymupdf pymorphy3 ezdxf
```

`ezdxf` — чтение DXF и DWG (ставится сам при первой проверке DXF/DWG). Для DWG нужна ещё
бесплатная программа **ODA File Converter** (opendesign.com → Guest Files → ODA File Converter):
она переводит DWG в DXF. DXF читается без неё.

`pymorphy3` — словарь русского языка для проверки орфографии; если его нет, программа
попробует поставить его сама при первой проверке.

Двойной щелчок по `Ordinem servare.pyw` — откроется окно программы.

**Ярлык на рабочем столе:** двойной щелчок по `Создать ярлык на рабочем столе.pyw` (один раз)
или в программе: Настройки → «Ярлык программы». Появится ярлык «Ordinem servare» со своим
значком на рабочем столе и в меню «Пуск»; программа открывается без окна консоли.
Если папку проекта перенесли — создайте ярлык заново.
Для аудита через API Claude дополнительно: `python -m pip install anthropic` и ключ API в настройках.

## Файлы

| Файл | Назначение |
|---|---|
| `Ordinem servare.pyw` | запуск программы |
| `Создать ярлык на рабочем столе.pyw`, `ov_shortcut.py` | ярлык на рабочем столе и в меню «Пуск» |
| `ov_app.py`, `ui.html` | окно программы (локальный сервер + интерфейс) |
| `ov_audit.py` | полный прогон проверки |
| `ov_check.py` | подписи сечений воздуховодов против геометрии PDF |
| `ov_album.py` | штамп, шифр, состав комплекта, обозначения, спецификация |
| `ov_tech.py` | технические проверки по СП РК 4.02-101 |
| `ov_norms.py` | база нормативов: разбор PDF, Word и TXT по пунктам и поиск |
| `ov_word.py` | чтение документов Word (.docx, .doc, .rtf) |
| `ov_cad.py` | чтение DWG и DXF: перевод листов чертежа в PDF со слоями и текстом |
| `ov_spell.py` | проверка орфографии (словарь pymorphy3 + слова из нормативов + `Справочники\Словарь.txt`) |
| `ov_marks.py` | PDF с комментариями |
| `ov_report.py` | сводный отчёт |
| `ov_ai.py` | аудит Claude через API (по желанию) |
| `ov_config.py`, `Справочники/` | справочники оборудования и слоёв (правятся в Excel) |

Нормативные документы в репозиторий не входят: программа читает PDF, Word (.docx, .doc, .rtf) и TXT из папки
`Рабочий стол\Нормативная документация для проверки` (другую папку можно выбрать
во вкладке «Нормативы»), включая все вложенные папки.
.docx читается сам; для старого .doc и .rtf нужен установленный Microsoft Word или LibreOffice
(.doc, сохранённый с adilet.zan.kz, на самом деле HTML и читается без них).
